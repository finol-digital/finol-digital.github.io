# Finol Digital

The public project directory for **https://finol.digital**, hosted by the organization repository **finol-digital/finol-digital.github.io** on GitHub Pages.

## Directory

The build fetches all pages of the organization's public repository list from GitHub without credentials and includes only explicitly public repositories. Projects with GitHub Pages link to their websites; all other projects link to their repositories, regardless of their homepage field. Archived repositories and forks remain included if public. This repository also appears in the directory.

GitHub Actions rebuilds and deploys on every push to `main`, daily at 08:23 UTC, or manually through **Actions → Publish project directory → Run workflow**. GitHub can delay scheduled runs or disable them after 60 days of inactivity in a public repository; re-enable the workflow if necessary. The deployed page is static, accessible without JavaScript, and makes no visitor-side API requests. An API failure stops deployment, preserving the last successful site. Visibility changes appear after the next successful deployment.

## Shortcuts

- `/cgs` (and `/cgs/`) → `https://finol-digital.github.io/Card-Game-Simulator`
- `/dominoes` (and `/dominoes/`) → `https://finol-digital.github.io/dominoes-tournament/`

GitHub Pages adds the trailing slash for directory paths. Each shortcut uses a browser redirect with a meta-refresh and clickable link fallback. JavaScript preserves query parameters and fragments, including `?tv=1` for Dominoes. These are static HTML redirects, not custom HTTP 301 rules. GitHub may then redirect the destination to the project's custom domain.

## Hosting and domain

Set this repository's **Settings → Pages → Source** to **GitHub Actions**, then set the custom domain to `finol.digital`. Because this site uses an Actions deployment, the custom domain lives in the repository's Pages settings rather than a CNAME file.

In Porkbun's DNS settings for `finol.digital`, replace only the parking/forwarding records for the apex and `www` with:

| Type | Host | Answer |
| --- | --- | --- |
| A | (blank / apex) | 185.199.108.153 |
| A | (blank / apex) | 185.199.109.153 |
| A | (blank / apex) | 185.199.110.153 |
| A | (blank / apex) | 185.199.111.153 |
| CNAME | www | finol-digital.github.io |

Keep unrelated mail, TXT, and other service records. Remove any conflicting apex AAAA parking records if present. Optional IPv6 records are documented by GitHub. Do not configure URL forwarding for the domain: GitHub serves the homepage directly. Once GitHub finishes DNS verification and certificate provisioning, enable **Enforce HTTPS**. Domain verification in the organization's Pages settings is also recommended; it requires the exact TXT value generated by GitHub.

An organization custom domain is inherited by project sites without their own domain. Dominoes will therefore also be served at `https://finol.digital/dominoes-tournament/`. Card Game Simulator keeps `https://www.cardgamesimulator.com/`. Existing browser storage is tied to a site's origin: export any ongoing Dominoes event before switching domains and restore it at the new address.

- [GitHub custom domain setup](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)
- [Porkbun GitHub Pages instructions](https://kb.porkbun.com/article/64-how-to-connect-your-domain-to-github-pages)

## Local development

Requires Node.js 22 or later. No packages need installing.

```sh
npm test
npm run build
python -m http.server 8080 --directory _site --bind 127.0.0.1
```

Edit `template.html`, `public/style.css`, or the shortcut pages under `public/`. Generated output goes to ignored `_site/`; deployments upload only that folder, not the repository source.
